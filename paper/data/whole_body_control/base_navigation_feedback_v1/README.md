# Signed base navigation feedback

See [the report](../../../../docs/experiments/base_direction_bootstrap_20261116.md).
This is a fixed-weight architectural/control intervention, not a PPO learning
win. It retains learned magnitudes, imposes base-only sign/symmetry conventions
and uses a declared coarse hold region. The opt-in config is checksum-bound in
v3 bundles; older runtimes reject it. Active-hand mapping is unchanged.

Complete native cohorts, including static endpoint failures, are retained.
Repeated source versions are distinct producers and are not pooled as
independent trials. Mars supplies physical evidence; Stretch has unit coverage.
Raw traces, source archives, bundles, XML and receipts remain ignored. No
hardware use, loaded-manipulation qualification or automatic promotion follows.
