# Arm-only mix candidate

The case manifest preserves the 32-case candidate byte for byte. Each split
contains 16 cases, including four fixed-base arm-only cases. Only the training
split is eligible for PPO. The protocol records the current source digest and
the preceding fine-tune as a candidate initializer.

The recovered admission log had 25 rows, including eight native process
crashes. Recheck the teacher in a fresh process for each case, retaining
native process exit codes and checking stop confirmation and safety flags
before and after stopping. The recovery directory is
`logs/recovery/arm-only-mix-v1`.

A fresh source-bound regression receipt and complete teacher recheck are
required before launching. The protocol is preparation for a simulator
experiment. The PPO budget and launch command have yet to be frozen.
