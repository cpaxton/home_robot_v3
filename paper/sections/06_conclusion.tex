\section{Conclusion}
\label{sec:conclusion}

We introduced Dynagraph, a dynamic scene-graph memory system for exploring robot agents that combines DynaMem voxel navigation with GraphEQA-style graph memory and explicit merge/staleness lifecycle rules.
The open-source \texttt{emet} implementation enables the same EQA loop across MuJoCo, Robocasa, and MolmoSpaces, with a Habitat harness that now runs end-to-end HM-EQA episodes on held-out question slices.
An optional agentic tool-calling controller (retrieve place evidence, navigate / VLM frontier explore, detector proposals, VLM assess / submit) is a first-class ablation against the classic planning loop on the same memory: on the matched holdout-8, agentic answers 8/8 vs.\ classic 5/8 with roughly $3\times$ fewer planning steps, and on balanced-32 it maintains a 16/32 vs.\ 9/32 letter edge while cutting mean steps significantly---making search efficiency the statistically robust claim and the holdout letter win the same-policy headline.

Future work includes completing the full 113-question Habitat sweep against GraphEQA API baselines, scaling classic vs.\ agentic verify beyond holdout gates, releasing curated EQA question sets for Robocasa/Molmo, tighter comparison to DREAM-style continuous map pruning, and real-robot home episodes.
