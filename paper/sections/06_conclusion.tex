\section{Conclusion}
\label{sec:conclusion}

We introduced Dynagraph, a dynamic scene-graph memory system for exploring robot agents that combines DynaMem voxel navigation with GraphEQA-style graph memory and explicit merge/staleness lifecycle rules.
The open-source \texttt{emet} implementation enables the same EQA loop across MuJoCo, Robocasa, and MolmoSpaces, with a Habitat harness underway for direct comparison to GraphEQA benchmarks.

Future work includes completing Habitat-scale evaluation, releasing curated EQA question sets for Robocasa/Molmo, tighter comparison to DREAM-style continuous map pruning, and real-robot home episodes.
