\section{Background and Related Work}
\label{sec:background}

\subsection{Embodied question answering and 3D scene graphs}

\textbf{GraphEQA}~\citep{saxena2024grapheqa} builds a real-time 3D metric-semantic scene graph (3DSG) and selects task-relevant images to ground a VLM for EQA in unseen environments, with semantics-guided hierarchical exploration.
It is evaluated in Habitat-Sim on HM-EQA (113 HM3D questions) and an OpenEQA subset, and demonstrated on a Stretch robot in real homes.
Our \texttt{emet} stack re-implements graph-based EQA memory without the Hydra/ROS pipeline, using a lighter sensor-to-graph builder (\texttt{SensorGraphBuilder}).

\textbf{GraphPad} (2025) introduces a mutable scene graph updated via agent API calls during a task; Dynagraph instead updates memory automatically from streaming perception during exploration.

\textbf{M3Fusion} (2026) fuses 2D semantics and 3D geometry into unified 3D tokens for LLMs on 3DQA benchmarks---complementary representation focus, not an embodied exploration loop.

\subsection{Feed-forward geometric perception and streaming mapping}

A parallel line of work replaces classical bundle adjustment with \emph{feed-forward} geometric foundation models (GFMs) that predict depth, pose, and dense structure from casual RGB.
\textbf{VGGT}~\citep{wang2025vggt} is a representative GFM: a single transformer forward pass estimates cameras, depth, point maps, and tracks from one to hundreds of views, enabling downstream SLAM and reconstruction pipelines without per-scene optimization.

\textbf{Depth Anything 3} (DA3)~\citep{lin2025depthanything3} pursues a minimal design---a plain DINO backbone with joint depth--ray prediction---and sets strong any-view pose and geometry benchmarks while improving monocular depth over DA2.
In \texttt{emet}, DA3 supplies metric depth when robots lack calibrated RGB-D (Appendix~\ref{app:da3}); Dynagraph and DynaMem consume the same resolved depth tensor whether it comes from sim sensors or DA3.

\textbf{ViPE}~\citep{huang2025vipe} is an open video annotation engine that estimates intrinsics, trajectory, and dense near-metric depth from unconstrained monocular footage (pinhole, wide-angle, or 360$^\circ$), scaling to large in-the-wild corpora for spatial-AI training data.

Hybrid systems wrap GFMs with lightweight optimization for \emph{online} mapping.
\textbf{VGGT-SLAM 2.0}~\citep{maggio2026vggtslam2} incrementally aligns VGGT submaps with a redesigned factor graph, uses VGGT attention for loop-closure verification, and runs in real time on a ground robot---including open-set 3D object queries over the reconstructed map.

Purely feed-forward \emph{streaming} mappers are emerging as an alternative to iterative SLAM backends.
\textbf{LingBot-Map}~\citep{chen2026lingbotmap} maintains a compact Geometric Context Attention state---anchor frames for scale grounding, a local pose-reference window, and compressed trajectory memory---and reconstructs long monocular sequences ($>$10k frames) at roughly 20\,FPS without a separate optimization stage.

Semantic mapping is beginning to merge with these geometric pipelines.
\textbf{RADIO-ViPE}~\citep{nasser2026radiovipe} tightly couples RADIO-style vision--language embeddings with a monocular pose/depth factor graph, enabling online open-vocabulary grounding of free-form language queries to 3D regions from uncalibrated RGB video in dynamic scenes.

Dynagraph is complementary to this trend: we assume a resolved RGB-D stream (sensor or DA3) and focus on \emph{object-level graph memory}---merge, staleness, and voxel-grounded nodes for EQA---rather than replacing front-end pose or dense mapping.
Foundation-model SLAM and streaming reconstructors are promising sources of pose, depth, and even open-vocabulary semantics; our contribution is the lifecycle-aware scene graph layered on DynaMem's dynamic voxels.

\subsection{Dynamic spatial memory for robots}

\textbf{DynaMem}~\citep{liu2024dynamem} proposes online dynamic spatio-semantic memory for open-vocabulary mobile manipulation: voxel/point-cloud memory with add/remove, value-based exploration, and the DynaBench offline benchmark.
Dynagraph uses DynaMem's voxel stack for navigation and adds a graph layer for EQA.

\textbf{OK-Robot}~\citep{liu2024okrobot} integrates open-knowledge models for zero-shot pick-and-place with a \emph{prescanned static} semantic map; DynaMem reports substantially higher success on dynamic objects than this static baseline.
Emet's voxel navigation code traces lineage to OK-Robot.

\textbf{DREAM} (2026) extends dynamic spatio-semantic memory with redundancy-aware pruning on a pose graph for long-horizon manipulation without a pre-built map.
Dynagraph's graph merge and staleness target \emph{discrete object nodes for EQA}, complementary to continuous map pruning.

\textbf{PanoNav} (2025) uses a bounded memory queue of visited places for loop-free navigation; Dynagraph retains full semantic voxel and graph structure for question answering, not only pose history.

\subsection{Dynamic memory for language agents}

\textbf{DeltaMem}~\citep{deltamem2026} stores experience as residual deltas in a dual-tree structure for LLM agents (ALFWorld, ScienceWorld, WebShop).
\textbf{$\delta$-mem} compresses history into a low-rank attention state during inference.
These works motivate \emph{incremental} and \emph{bounded} memory but do not address embodied 3D exploration; we cite them for the forgetting/update narrative only.

\subsection{Benchmarks}

We target \textbf{HM-EQA} and \textbf{OpenEQA}-style evaluation via a Habitat harness (GraphEQA parity) and complementary \textbf{Robocasa} / \textbf{MolmoSpaces} episodes in MuJoCo with multi-robot support in \texttt{emet}.
