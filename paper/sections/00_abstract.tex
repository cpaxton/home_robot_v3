\begin{abstract}
Embodied question answering (EQA) requires a robot to explore an unknown environment, build a semantic model of what it sees, and answer natural-language questions with sufficient confidence to know when to keep looking.
We present \textbf{Dynagraph}, a memory stack that couples a \textbf{DynaMem-style sparse voxel map} for navigation and exploration with a \textbf{GraphEQA-style object-centric scene graph} for vision-language grounding.
Dynagraph adds \textbf{spatial merge} of redundant graph nodes and \textbf{staleness pruning} of nodes not reinforced by recent observations, so memory stays compact and current as the robot moves and the scene changes.
We implement Dynagraph in the open-source \texttt{emet} stack (\texttt{emet run dynagraph}) and evaluate on \textbf{Habitat} (HM-EQA and OpenEQA-style benchmarks, via a dedicated harness) and on \textbf{MuJoCo simulation} (Robocasa kitchens, MolmoSpaces iTHOR, multiple robot embodiments).
Results and tables are pending harness and sim experiment runs.
\end{abstract}
