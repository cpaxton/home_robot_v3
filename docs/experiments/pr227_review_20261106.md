# PR 227 review follow-up

The review found no blocking controller correctness issue. This follow-up
addresses its four concrete test, validation, export and documentation notes.
It does not qualify or promote a learned policy.

1. The component tests share a helper module and a `conftest.py` fixture instead
   of importing another test module. The 76 targeted tests pass with pytest's
   `--import-mode=importlib`, including native MuJoCo cases. Regression receipts
   now bind helper, package and ancestor fixture sources as well as test modules;
   moving fixture code cannot remove it from the source fingerprint.
2. `validate_critic_reward_scale()` accepts the scalar directly. Manifest reads
   delegate to it and preserve the default of 1.0 for older bundles. Invalid
   units are rejected before export writes weights.
3. Component merges stage weights and both manifest updates in a temporary
   directory on the destination filesystem, reload and validate that bundle,
   restore the source model, then publish the directory with one rename.
   Metadata-write and publication failures clean up the stage without exposing
   a partial destination. Existing destinations are refused. The failure tests
   also check that source parameters and timestep accounting are restored.
4. The masked likelihood comment explains the independent Gaussian factors:
   summing only active dimensions gives the active marginal. Inactive requests
   are deterministic and contribute no likelihood, entropy or gradient.

The optional module split is deferred. Policy and optimizer classes already
appear in saved SB3 checkpoints, so a split should deliberately preserve their
import paths and demonstrate reload compatibility rather than accompany this
small review cleanup.

The ongoing 300-to-1 gain-bias learning-rate control runs from the unchanged
`2227f58a` snapshot. Its original regression receipt remains specific to that
snapshot. These changes require a fresh receipt; they do not retroactively
change any experiment's source identity. Hardware motion and automatic policy
promotion remain disabled.
