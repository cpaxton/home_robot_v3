# Nori A3 (emet backend)

[Nori A3](https://www.norirobotics.com/) is a 19-DoF **bimanual mobile manipulator**
(Nori Robotics): a 45×45 cm differential base, a three-stage telescoping lift
(69→145 cm, floor-to-counter reach), and two 7+1 DoF arms (1.5 kg payload each) with
four cameras (head, neck, per-gripper). It ships assembled for $1,688.

## Asset

Vendored under `src/emet/assets/robot/nori_a3/`:

- `nori_a3.xml` — MJCF derived from the official
  [`Nori-Robotics/nori_description`](https://github.com/Nori-Robotics/nori_description)
  URDF (kinematics verified against hardware). The base is a **freejoint** (differential
  wheels are fixed visuals — base motion is nav teleport); 17 **named** position
  actuators (1 lift + 14 arm + 2 driven grippers); four cameras; **primitive collision
  geoms** from the URDF (visual meshes are dropped by the URDF→MJCF conversion —
  kinematics and collision are faithful). The URDF's **passive mimic joints** (lift
  middle stage at half the lift rate, gripper idler fingers mirroring the driven finger)
  are modeled as `<equality><joint>` gearings (MuJoCo 3.5 has no `mjEQ_MIMIC`): the
  passive joints exist, have **no actuators**, and are physically constrained so they do
  not float independently.
- `LICENSE`, `NOTICE` — vendored from the same repo. **License: CC BY-NC-SA 4.0**
  (research / simulation only, not commercial).

## Backend

`emet.robots.nori.NoriBackend` — registered as `nori` (alias `nori_a3`):

- `RobotSpec`: 21 joints, 17 actuators, 4 cameras, 0.45 m footprint.
- Curated per-arm `ArmChain`s (`arm_chains["left"/"right"]`): **8** joints each
  (`lift_extension_joint` + 7 arm joints `*_shoulder_pitch` … `*_wrist_roll`) so
  IK can lower the column for floor reach. EE = `*_wrist_roll_link`, grippers =
  the driven + idler finger links.
- `create_client` → `GenericZmqClient` (sim). Real hardware is driven through the
  **`nori-sdk`** operator client (WebRTC jog streams) — a full emet
  `AbstractRobotClient` adapter for real Nori hardware is a follow-up.

`ArmManipProfile.for_robot("nori", arm=…)` resolves via the curated chains, and the
robosuite server advertises `kinematic_manip` (latch pick/place on the merged MJCF).

## Sim

```bash
uv run emet serve mujoco --scene ithor --robot nori --headless
# or a dedicated config:
uv run python -m emet.simulation.mujoco_server --config configs/sim/molmospaces_ithor_train_nori_0.yaml
```

TAMP clutter episodes for `nori` are generated by
`scripts/generate_tamp_clutter_registry.py` (**`sim` teleport** on floor clutter;
`--manip-mode latch` for a latch experiment).
