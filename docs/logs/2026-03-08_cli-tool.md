## Commands

| Command | Purpose |
|---------|---------|
| `emet serve [mujoco]` | Start simulation server |
| `emet run <app>` | Run dynamem, mapping, grasp, chat, ai_pickup, timing |
| `emet sync` | uv sync or pip install -e . |
| `emet show <path.rrd>` | View Rerun logs |
| `emet test` | Run pytest (src/test/) |
| `emet install-completion` | Bash/zsh completion script |
