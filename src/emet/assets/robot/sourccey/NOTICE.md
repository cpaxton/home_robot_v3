# Sourccey Mk.V assets — provenance

The files in `upstream/` are copied from
https://github.com/vulcan-forge/sourccey-simulation-mujoco at commit
`c1059b0d15200fb91bd38ac276a7ac47758e4b26`.
That repository supplies the MIT license, reproduced unchanged in `upstream/LICENSE`
(Copyright (c) 2026 Vulcan Robotics).

`upstream/manifest.json` records per-file SHA-256 hashes and the hardware repository
revision against which the full-body URDF was checked byte-for-byte:
https://github.com/vulcan-forge/sourccey-hardware at
`dbb4bfd72108d7a79b1b27a87619aa260e71a953`.
The hardware repository at this revision does not contain the LICENSE file previously
linked by this project; we do not assert a separate hardware license here.

`sourccey.xml` is a derivative generated by `scripts/robot_assets/assemble_sourccey.py`:
world-aligned planar base, fixed wheels, Emet joint/actuator names, hardware URDF arm
limits, raised-arm home clipped to those limits, visual-only robot geometry, and
namespaced floor assets. Both actual arm chains, CAD inertials, camera poses and
lidar mount are retained. The untouched upstream MJCF remains in `upstream/models/`.

CAD inertials are not verified physical masses (upstream total: 169.042 kg). Camera
poses and lidar mounting are provisional. See `upstream/models/source/SourcceyURDF/README.md`
and the camera/lidar JSON metadata for upstream caveats.

Regenerate with:

```bash
uv run python scripts/robot_assets/assemble_sourccey.py
```

For updates, use `scripts/robot_assets/sync_sourccey.py` with clean simulator and
hardware checkouts. See `docs/robots/sourccey.md` for the full workflow and hardware
bring-up requirements. Do not hand-edit generated assets or the upstream snapshot.
